# 와랑 AEO 블로그 스튜디오

곽도연 강사의 네이버 블로그 복붙용 글 작성기 (설치 없는 단일 HTML 웹앱).

- 주제 → GPTs(`곽도연강사-AEO블로그`)에 붙일 프롬프트 자동 생성 (API 비용 0원)
- 원고 → 네이버 스마트에디터 ONE 서식(HTML+텍스트)으로 변환·복사
- 사진 파일명 검색 노출용 일괄 변경(`제주AI강사추천_곽도연_…`) + ZIP 다운로드
- (선택) OpenAI API 키를 넣으면 원고 초안까지 한 번에

모든 처리는 브라우저 안에서만 이뤄지며, 입력값은 사용자 브라우저의 localStorage에만 저장됩니다.
